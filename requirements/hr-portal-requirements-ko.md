# 탕콤 임직원 포털(TCM Employee Portal) 요구사항 — 샘플(데모용)

> **데모용 축소 요구사항.** AI-DLC Inception·Construction을 짧게 시연하기 위한 최소 범위입니다.
> 실제 프로젝트 요구사항은 출장 실사 후 확정합니다.

## 1. 개요
탕콤 임직원이 **휴가 신청**과 **공지 확인**을 모바일로 처리하는 셀프서비스 포털(샘플 범위).
현장직 비중이 높아 모바일 우선이며, **한국어·영어·베트남어 3개 언어**를 지원한다.

## 2. 주요 사용자
- **임직원**: 로그인 후 휴가 신청, 공지 확인
- **관리자(HR)**: 휴가 결재, 공지 등록

## 3. 핵심 기능 (샘플 범위)

### 임직원
1. **로그인** — 사번 + 비밀번호로 로그인. 로그인 후 언어(한국어/영어/베트남어) 선택·전환
2. **휴가 신청** — 연차/반차 신청, 처리 상태(대기/승인/반려) 확인
3. **공지 열람** — 공지 목록·상세 보기

### 관리자(HR)
4. **휴가 결재** — 신청 승인/반려(반려 사유 입력)
5. **공지 등록** — 공지 작성·게시

## 4. 다국어 요구사항 (필수)
- 모든 화면 UI 문구를 **한국어 / 영어 / 베트남어**로 제공
- 사용자가 언어를 선택하고 언제든 전환 가능
- 로그인 시 기본 언어 선택

## 5. 비기능 요구사항 (최소)
- 모바일 우선(현장직 다수), PC 병행
- 로그인 인증, 개인정보 보호
- 다국어(한/영/베) 지원

## 부록 — 용어
- **셀프서비스 포털**: 임직원이 담당자 개입 없이 직접 처리하는 시스템
- **결재선**: 신청이 거쳐야 하는 승인자 순서
