# TCM Employee Portal — Requirements (Sample / Demo)

> **Trimmed sample requirements** to keep the AI-DLC Inception/Construction demo short.
> Actual project requirements will be finalized after the on-site visit.

## 1. Overview
A self-service portal where TCM employees handle **leave requests** and **announcements** on mobile (sample scope).
Mobile-first (many shop-floor staff), with **Korean, English, and Vietnamese** language support.

## 2. Primary Users
- **Employees**: log in, request leave, view announcements
- **Admin (HR)**: approve leave, post announcements

## 3. Core Features (sample scope)

### Employee
1. **Login** — employee ID + password. After login, choose/switch language (Korean / English / Vietnamese)
2. **Leave request** — request annual/half-day leave; check status (pending / approved / rejected)
3. **Announcements** — view list and detail

### Admin (HR)
4. **Leave approval** — approve/reject (with reason)
5. **Post announcement** — write and publish

## 4. Multilingual Requirement (mandatory)
- Provide all UI text in **Korean / English / Vietnamese**
- Users can choose and switch language at any time
- Default language selected at login

## 5. Non-Functional Requirements (minimal)
- Mobile-first (many shop-floor staff), PC as well
- Login authentication, personal-data protection
- Multilingual (KO / EN / VI)

## Appendix — Glossary
- **Self-service portal**: employees handle tasks directly without staff intervention
- **Approval line**: the sequence of approvers a request must pass
